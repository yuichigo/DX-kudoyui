# 子育て世代向け地域コミュニティ参加支援アプリ

## 概要

子育て世代が地域活動へ参加するきっかけを提供することを目的としたWebアプリケーションです。

地域のイベントやコミュニティ情報を一覧で確認でき、イベント検索や予約、口コミ閲覧などの機能を通して、地域コミュニティへの参加を支援します。

本アプリは大学のDX企画課題として制作しました。

---

## 解決したい課題

- 地域イベントの情報が届きにくい
- 子育て世代が地域活動へ参加するきっかけが少ない
- 地域コミュニティの希薄化

---

## 主な機能

### ホーム画面

- おすすめイベント表示
- 新着イベント表示
- 地域コミュニティ一覧
- イベント検索

### イベント

- イベント一覧表示
- キーワード検索
- イベント詳細表示
- イベント予約

### コミュニティ

- コミュニティ詳細表示
- 開催イベント一覧表示

### マイページ

- プロフィール表示
- 子どもの情報表示
- 予約済みイベント表示
- 参加履歴表示

### 口コミ

- イベントごとの口コミ表示
